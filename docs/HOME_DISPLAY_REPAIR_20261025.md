# 首页照片与弹窗展示修复

## 原因

- 生产有5份照片预建档，均为DRAFT；客户可预约列表只读取已发布、有真实技师权限和排班的档案，因此列表为空。
- 首页弹窗接口启用且返回200，但客户端7.6.2只上传开发/体验包，尚未正式审核发布。旧正式包没有此功能。
- 弹窗旧实现请求成功就记录当天已看过；定位、登录或切后台导致页面隐藏时，弹窗可能还没被用户处理就被记为已展示。

## 修复

- 新增单张形象照的独立发布状态和只读风采接口。只返回明确选择的形象照，不公开空白申请、内部账号ID、实名、手机号、证件或其他相册图片。
- 首页和技师列表增加技师风采，支持点开大图；明确显示预约待开放。保持资料审核、技师权限、项目和排班的原有接单条件。
- 后台照片预建档新增展示、撤下、更新头像展示按钮，保留组织权限、动态码及版本并发校验。
- 客户端主动关闭或打开活动才记录当天频次；页面隐藏不会消耗展示机会。始终保留查看活动入口，可以再次打开当前有效活动。
- 受控初始化仅针对已恢复的前5张原图来源档案，按导入审计与摘要校验，不补造个人资料、不批准申请、不授予接单权限。旧活动版本1只升到2一次，重跑不反复重置频次。

## 验证

- API形象照与活动13项，后台现有290项，首页及网关相关检查通过；API、后台、小程序构建通过。
- 独立临时PostgreSQL数据库应用43次迁移，验证未发布不可读、单张归属、跨组织拒绝、并发版本校验、无审核或接单授权、关联本人申请后撤回展示、手动撤下。临时库已删除。
- 代码部署、图片线上可读、小程序体验包上传和正式发布分别记录；未正式发布时不得宣称普通用户的正式入口已更新。
