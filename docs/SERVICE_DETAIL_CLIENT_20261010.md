# 客户端项目详情与预约展示

本轮只更新小程序客户端，不新增数据库迁移，不改变支付、退款或提现规则。

## 项目详情

新增 `/pages/service-detail/index?slug=…`。首页及服务列表项目卡增加“项目介绍与服务流程”独立入口；原有点卡片查看真实可约技师的行为保留。技师项目卡和预约页也可查看详情。

详情显示后台已发布的名称、简介、完整说明、价格、时长、步骤、服务边界及公开评价。全部复用现有目录、评价及排班 API；管理员修改目录后，客户端重新打开或刷新即可读取新值，无需复制一套数据。

没有真实技师、未公开资料或暂无时段时仍能浏览项目，但不制造技师身份、排班、评价或可支付订单。排班读取失败与成功的空列表分别提示。返回页面重新读取数据，离开后忽略迟到响应。

现有目录没有项目图片字段，使用代码绘制的绿色示意插画并明确标注“非服务实拍”，不把技师头像冒充项目实拍。服务流程严格显示后台步骤，不默认加入未确认的嗅吸、面部拨筋或治疗性操作。九项预约提醒及用品检查提示属于通用用户须知，不代表任何一次履约已执行。

## 技师详情和预约页

技师详情按“推荐项目、全部项目、用户评论、商户动态”展示，保留真实简介、照片、资质、预约时段和选中项目优先行为。无动态接口时明确显示待发布，不生成虚构动态。

预约页地址前置，补项目详情入口，提升辅助字号、字重与对比度。数量仍为服务器支持的单项预约；微信与好友代付保留原有服务器核价、优惠和幂等处理。

当前订单契约和数据库没有备注保存字段，因此本轮不添加无法保存的备注输入框。支付宝未接通，不添加不可用支付按钮。首充、钱包和提现政策均保持不变。

## 验证

专项页面测试覆盖后台真实字段、无资料/无时段、排班失败、评价失败、非零出行费拦截、登录门禁、未知参数、迟到响应和卡片独立入口。继续执行全部小程序页面、好友代付、报价优惠及支付重试回归，并通过微信开发工具编译上传。开发版上传及预览码不等于小程序正式版发布。
