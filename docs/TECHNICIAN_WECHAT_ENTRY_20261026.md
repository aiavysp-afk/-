# 技师扫码微信授权入驻

## 用户流程

1. 微信扫描技师专用小程序码，进入 `pages/technician-onboarding/index`。
2. 在同一页阅读并勾选协议，点击微信授权按钮，原生授权确认本人手机号；不输入短信、密码或配对码。
3. 单次微信与手机号原子登录保留原微信/手机号账号。新技师创建本人草稿；草稿或驳回申请直接进入资料表单，待审核显示进度，审核通过由服务端验证后进入技师工作台。
4. 表单沿用本人资料、形象照、证件、擅长项目等上传与提交接口；提交和审核结果同步现有管理后台，不批准任何真实申请。

## 身份与权限

- 复用 `loginCustomerWithWechatPhone` 的单次原子登录，不能先用新OpenID建立另一用户后再尝试绑定旧技师手机号。
- 手机号入驻技师首次绑定微信，只有满足现有服务端同一已验证手机号、无其他冲突身份和无管理安全凭据等条件，才附着到原User；不迁移、合并或替换其他现有账号。
- 旧的客户短信会话不会被前端标记为技师微信会话；所有入驻和工作台权限仍由服务端检查本人身份、已验证手机号、审核状态及组织成员资格。
- 登录失败、取消授权、超时、过期401及页面卸载不自动提交资料，不重复创建申请，不把技师退回客户通用登录页。
- PC运营后台的网络、密码、MFA与权限规则不变。

## 网页与二维码

- 技师网页主入口展示微信专用入驻二维码，明确扫码后在小程序授权填写资料；不声称网页自身取得扫码会话。
- 手机号验证码入口收在其他登录方式中，已有手机号会话仍可继续使用。
- 当前生成的是官方体验环境小程序码，路径存在于上传包中；入口尚未进入正式发布版本，正式路径检查返回41030。因此图片和网页必须明确体验成员限制，不能冒充全员正式码。
- 正式审核发布后，另生成并核验release环境入口，再替换当前体验码。不得通过H5无服务号的OAuth路径伪造授权成功。
