# 客户端个人中心实现说明

更新时间：2026-10-09

## 当前状态

本轮在既有工程上增量完成微信客户端个人中心，不重写技师端或管理端，也未连接生产数据库、上传微信版本或提交审核。客户端、NestJS API、PostgreSQL/Prisma 与管理后台使用同一份组织和客户数据。

## 客户端页面

| 页面                          | 小程序路由                     | 数据来源                             |
| ----------------------------- | ------------------------------ | ------------------------------------ |
| 我的                          | `pages/profile/index`          | 客户中心聚合、订单状态、后台运营文案 |
| 我的优惠券                    | `pages/coupons/index`          | 当前客户真实优惠券                   |
| 储值卡与账单                  | `pages/stored-value/index`     | 当前客户真实余额、卡片和流水         |
| 设置                          | `pages/settings/index`         | 当前账号与后台客服配置               |
| 账号与安全                    | `pages/account-security/index` | 脱敏手机号、软注销申请               |
| 地址管理                      | `pages/addresses/index`        | 当前客户加密地址簿                   |
| 发现                          | `pages/discover/index`         | 已发布服务、已审核技师资料           |
| 消息                          | `pages/messages/index`         | 当前客户订单状态与后台快讯           |
| 收藏/足迹/投诉/反馈/关于/快讯 | `pages/customer-records/index` | 真实空状态、后台反馈接口或后台文案   |

全局导航调整为“首页、发现、下单、消息、我的”，中间“下单”为圆形主操作。非 Tab 页面使用普通页面跳转并提供返回栏。

## 地址与下单联动

- 地址支持手动填写和高德定位，统一使用 GCJ-02。
- 手动地址在保存前调用 `/locations/address-geocodes` 获取坐标，禁止使用 `0,0` 占位。
- 预约页读取真实地址簿，自动带入默认地址，也可切换其他地址。
- 地址带入后仍调用 `/locations/address-verifications` 做服务范围核验，不绕过原下单校验。
- 用户手工修改地址或门牌号后，旧坐标、旧核验结果和旧报价会被清除并重新计算。
- 完整地址不写入小程序本地缓存；数据库中的联系人、手机号和详细地址均加密。

## 后端与后台同步

客户端接口统一位于 `/v1/customer-center`，包含个人中心聚合、优惠券、储值卡、账单、设置、地址、反馈和软注销申请。管理后台新增“客户中心”，通过下列组织级接口维护运营文案并查看脱敏汇总：

- `GET/PATCH /v1/admin/organizations/{organizationId}/customer-center/config`
- `GET /v1/admin/organizations/{organizationId}/customer-center/summary`

后台汇总仅返回订单、优惠券、储值账户、反馈和注销申请的聚合数据，不返回地址、反馈正文、联系方式或注销原因。相关权限为 `customer-center.manage`。

## 数据与安全边界

- 个人中心只读取真实优惠券、储值卡和账单，不自动生成演示资产。
- 储值充值尚未完成合规资金接入，接口明确返回不可充值，客户端不会引导向个人账户转账。
- 每位客户在每个组织最多保存 50 个地址，数据库保证同一客户、同一组织只有一个默认地址。
- 反馈正文和联系方式加密保存；每位客户按上海自然日最多提交 10 次。
- 显式组织必须有已发布服务，或客户在该组织有历史订单，否则拒绝客户中心写入。
- 注销为平台账号软注销申请，不硬删除交易和审计记录；每位客户全局最多一个待处理申请。
- 余额在“我的”页固定脱敏为 `****`，只在储值卡页向本人会话展示真实金额。
- 收藏与足迹目前没有持久化接口，因此只显示诚实空状态，不伪造数据。
