# PC 管理后台独立登录首页

## 最终行为

- 访问后台网址时，无会话的浏览器通过 SPA 固定跳转到 `/login`，只显示绿白品牌登录首页和已有账号密码登录表单。未登录不挂载侧栏、业务模块或业务数据请求。
- 账号密码及本人短信验证成功后进入经营概览，地址回到 `/`。保留账户安全入口；敏感操作仍遵守现有动态码验证。
- 恢复浏览器会话时先通过 `/auth/me` 确认身份和后台管理成员资格。验证等待期间不挂载工作台，读取设置10秒截止；网络异常可重试，不把临时异常当作会话过期。
- 正常退出或服务端确认会话过期后，清理会话并返回 `/login`。旧请求不能覆盖退出后的状态或新登录的身份。
- 跳转仅使用固定站内地址，不接受查询参数提供的外部跳转目标。

## 部署范围

仅更新私有 PC 后台前端。已有私有适配器支持 `/login` 的 GET/HEAD SPA 回退，无需改动 nginx、API、数据库、账号密码、短信通道、角色权限或 IP 白名单。

保留原有 `admin` 登录别名及用户本人此前设置的密码，不重设密码，不代替用户发送短信或输入验证码，不宣称本人登录已完成。

- 只读独立复核确认未登录不挂载业务模块，已有 MFA/权限校验保持不变。
