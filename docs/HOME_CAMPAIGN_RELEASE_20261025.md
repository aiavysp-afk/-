- 首页使用绿金色透明底横版 LOGO，原图位于 `apps/miniapp/assets/brand/zhongyuan-premium-logo.png`。由内置 imagegen 生成，提示词要求准确中文“中原到家”、屋檐与关怀手势/叶片、深绿与香槟金、透明背景、简洁高级。
