# 后台交互缺陷修复验收（2026-10-17）

## 修复范围

- 账户安全状态读取按身份和请求世代隔离，旧读取不能覆盖新动态码验证结果。
- 可选的验证器恢复队列故障不再抹去已成功读取的本人 MFA 状态。
- 业务接口返回 401 时，通过同一身份的去重只读 `/auth/me` 校验确认登录是否失效；输错动态码、权限不足、服务暂不可用不等同于注销。不重试原写入请求。
- 确认会话失效后清空根身份和私有页面，重新展示登录入口。旧身份或旧登录世代的迟到请求不得注销新身份。
- 服务项目列表隔离身份和读取世代，退出登录立即隐藏原管理目录，公开目录不显示管理按钮；读取失败不保留旧私有行。
- 排班读取隔离身份、组织、日期及请求世代，旧日期结果不得覆盖当前日期。创建只使用当前已读取的组织技师及所选日期，进行中禁止切日期和重复提交。
- 取消整页 1120px 最小宽度，窄窗仍可使用登录及导航。导航与宽表格各自在本区域滚动，保留表格右侧操作入口，不通过隐藏整页溢出掩盖布局问题。

## 不变的边界

不修改数据库、接口权限、手机号、密码、动态码凭据、成员角色、资金配置、短信额度或访问白名单。不替本人确认微信登录、设置密码或填写验证码。不上传、覆盖、审核或发布小程序。

正式库的账号初始化与真人登录验收仍需本人完成，不能用合成组件测试或匿名探针代替。本次未登录情况下不读取或伪造业务私有数据。

## 验收与部署

1. 真实组件异步替身测试复现并覆盖旧安全状态、恢复队列故障、输错动态码、身份切换、迟到 401、错日期排班与重复提交。替身仅使用合成身份，无正式凭据或网络业务写入。
2. 运行 `pnpm test`、`pnpm typecheck`、`pnpm build`；运行既有私有代理和 Nginx 回归测试。
3. 提交精确版本后，沿现有受控部署脚本发布 API 源目录、私有后台和同版本 Nginx。API 业务源码及数据库迁移未变，迁移应为零待应用项。现有脚本仍先做数据库备份及健康检查。
4. 对比环境文件与访问白名单摘要，复查原认证开关、匿名受保护请求和服务健康状态，不发真实短信、不建立验收人员。
5. 浏览器核对新版窄窗布局及登录入口，记录修复前后页面宽度。私有业务操作留待本人完成登录后验收。

回滚沿用现有精确版本脚本机制；不删除数据库列、正式用户、订单或审计记录。

## 本轮本地结果

后台 25 个测试文件共 165 项通过，其中包含本轮新增的 53 项回归；私有代理、Nginx 和部署边界 99 项通过。全仓测试、类型检查及构建通过，API/技师端/合约/小程序未改部分复用了相同源码摘要的既有通过结果。独立复审未发现新增权限扩张或凭据泄露路径。

## 追加排查：微信登录按钮请求失败

在实际浏览器点击一次“发起微信后台登录”，页面显示请求失败；服务器同一时间的访问记录显示该请求在 Nginx 层返回 503，尚未进入登录接口。内置浏览器出口与原有白名单出口不一致，不能用本机命令行访问成功代替浏览器访问验收。

本次页面修复让非 JSON 的 503 显示明确的服务或网络访问受限提示；异常成功响应不再被当作空的配对成功；登录请求设置 15 秒超时，只允许本人手动重试，不自动重发。配对字段格式按现有服务端校验，到期仍由服务端裁决，避免电脑时钟偏差误阻登录。

只部署独立私有后台页面，不重新发布 API、技师端、小程序或 Nginx，不改变角色、动态码、密码、短信额度、环境文件或访问白名单。新增浏览器出口的单地址授权需另获用户明确确认；获准前不能将本次页面修复记为登录链路已打通。

追加验证：19 项传输及组件回归覆盖真实取消、响应体读取超时、时钟偏差、格式异常与手动重试；后台全量 184 项测试、类型检查和生产构建通过，既有私有代理及部署边界 73 项通过。

## 追加修复：首次登录与账号安全引导

实际浏览器已加载 `f471176` 管理页，停留在账号密码页且发送短信按钮禁用。只读汇总确认尚未配置后台密码、未激活验证器，既有配对没有手机批准或电脑领取记录；不能把此前能生成配对误记为真人登录完成。

- 密码表单说明账号格式、12–128 字符密码要求和禁用原因。首次使用显著引导先微信确认，再由本人完成验证器和密码设置，不自动创建账号，不泄露某个账号是否存在，不发送测试短信。
- 服务端判定配对失效、已处理或返回明确终态时，清理失效配对并显示手动重新发起入口；限流和暂时故障保留可恢复配对。不自动重试领取会话或其他写入。
- 本人密码配置、信任设备配置和设备列表分别读取并显示各自错误。设备故障不得遮蔽密码设置；旧快照明确标为未刷新状态，不能凭旧快照继续敏感操作。
- 待激活验证器密钥刷新后不可重新显示。提示本人仅在原发起会话使用已保存的验证器；若未保存或已经换会话，等待该次自创建起十分钟的待激活有效期结束，再用新微信登录重新开始。不得重发密钥、重置已绑定因子或改变 MFA 要求。

本轮仍只发布独立管理前端，不改变 API、数据库、访问白名单、短信预算、已有角色或小程序体验版。临时工作人员预览码仅用于打开既有确认页，启动参数为空，不承载配对或批准信息；正式身份确认和凭据设置须本人完成。

本地验收：后台 27 个测试文件共 212 项通过，类型检查与生产构建通过；既有代理及部署边界 73 项、工作人员小程序入口 11 项回归通过。独立复审确认终态恢复不自动重试领取，旧身份或旧读取不能恢复已失效状态，未新增权限或凭据写入路径。
